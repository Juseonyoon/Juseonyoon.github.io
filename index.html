Key Projects

1) 용접 로봇 자동화 — 비전 기반 용접선 추출 + 실시간 궤적 보정

One-liner: 비전 기반 부재 용접선 추출과 다축 로봇 궤적 실시간 보정으로, 소조립 구간의 용접 정밀도와 생산성을 동시에 확보한 로봇 공정을 구축했습니다.

  • 문제: 작업자가 매번 CAD 도면을 조정해 위치를 지정하고, 설계부서가 도면을 업데이트해야만 용접이 가능한 구조였습니다.
  • 해결: 실제 부재와 CAD 도면을 정합하던 기존 방식에서 벗어나, 촬영 한 번으로 용접선과 경로를 추출해 부재를 용접하는 시스템으로 전환했습니다.
  • 개발:
    • 비전 카메라로 부재 위치를 실시간 인식하고, AI 학습으로 용접 토치 교시점을 추출
    • 라인레이저 좌표 변환 알고리즘으로 로봇 궤적을 보정 → 산업용 통신으로 다축 로봇에 실시간 반영
    • 현장 데이터 기반 학습형 실시간 능동제어 알고리즘 개발 중
  • 기술: 조선 환경 검증 3D 비전 센서·사용자 중심 캘리브레이션 · 로봇 C# 컨트롤러 및 PLC·센서 실시간 연동 아키텍처 · AI 기반 용접선 추출 및 로봇 경로/자세 모션 알고리즘

2) 유도가열 기반 열간 곡성형 자동화

One-liner: 실시간 로봇 곡면 추종 알고리즘과 유도가열 기술로, 작업자의 기량에 좌우되던 성형 품질과 속도를 개선했습니다.

  • 문제: 기존 열간 곡성형 공정은 작업자의 숙련도·경력에 따라 품질 편차가 크고, 가열 위치·가공 시간이 개인마다 달랐습니다. 수작업 기반이라 데이터 확보 방법이 없어 자동화가 불가능했습니다.
  • 해결: 7축 산업용 로봇과 AI 비전으로 획득한 데이터를 바탕으로, 목표 곡률과의 차이를 계산해 자동으로 보정하는 방식으로 공정을 전환했습니다.
  • 개발:
    • 비전 기반 부재 형상 추출, 설계도면과의 정합도 판별
    • 센서 기반 실시간 곡면 추종 알고리즘 개발
    • 가열 조건(전압·효율·로봇 속도·가열폭)을 능동 제어해 부재 형상을 설계형상과 동일하게 변형
    • 전기·냉각·센서 배선을 회피하며 부가축 위치를 능동 제어하는 알고리즘 개발
  • 기술: 다축 로봇 곡면 추종 궤적계획 · C#/PLC 연동 실시간 SW · 3D 부재 형상 인식 및 정합도 분석 · 작업자 암묵지를 학습 가능한 데이터셋으로 옮기는 스키마 설계
